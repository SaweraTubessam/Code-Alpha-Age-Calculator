# AgeWise — Age Calculator

A premium, animated web-based Age Calculator built for the **CodeAlpha Web Development Internship**.

## Features

- 🎂 Calculates exact age in **Years, Months & Days**
- ⏱ Extended stats: Hours, Minutes, Seconds, Weeks lived
- 🎉 Days until next birthday + day of week born
- ✨ Animated number counters with easing
- 🌟 Floating particle canvas background
- 🎨 Luxury dark theme with gold accents
- 📱 Fully responsive (mobile, tablet, desktop)
- 🔍 Form validation with helpful error messages
- 🖱 Scroll-reveal animations for sections

## Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — custom properties, grid, flexbox, keyframe animations
- **JavaScript (ES6+)** — Date object, Intersection Observer, Canvas API

## How to Run

Simply open `index.html` in any modern browser. No build tools or dependencies required.
