✦ About

Built with Precision

AgeWise is a pure HTML, CSS, and JavaScript application that calculates your exact age with precision — down to years, months, days, hours, minutes, and seconds.

Crafted as part of a CodeAlpha Web Development Internship, this project demonstrates mastery of the JavaScript Date object, responsive design, and modern CSS animations.
